This is a app that was built following this demo https://www.youtube.com/watch?v=vCIsrOGNhas


## 🛠️ Tech Stack: ##
- Framework: Next.js 16 (App Router)
- Language: TypeScript
- UI Library: React 19
- Styling: Tailwind CSS 4
- Database: MongoDB with Mongoose
- Authentication: Better Auth
- Drag & Drop: dnd-kit
- UI Components: Radix UI
- Icons: Lucide React
